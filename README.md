# Data Visualization with Python

## 📖 Overview  
This notebook explores **data visualization techniques in Python** to effectively communicate insights from datasets.  
It demonstrates how to build **informative, aesthetically pleasing, and interpretable plots** using popular libraries such as **Matplotlib**, **Seaborn**, and **Plotly**.

---

## 🧩 Learning Objectives  
- Understand the importance of data visualization in data analysis  
- Create different types of charts and plots for data exploration  
- Customize plot styles, color palettes, and layouts  
- Visualize distributions, relationships, and correlations between variables  

---

## 📈 Visualization Topics Covered  

### 1. **Matplotlib Basics**  
- Line plots, bar charts, scatter plots  
- Figure and axes customization  
- Grid, labels, legends, titles, and styles  

### 2. **Seaborn for Statistical Visualization**  
- Distribution plots (`distplot`, `histplot`, `kdeplot`)  
- Relationship plots (`scatterplot`, `pairplot`, `regplot`)  
- Categorical plots (`boxplot`, `violinplot`, `barplot`, `countplot`)  
- Correlation heatmaps and styling  

### 3. **Plotly for Interactive Visualizations**  
- Interactive line and scatter charts  
- Hover and zoom features  
- Combining multiple traces in one figure  

---

## 🛠️ Technologies Used  
- **Python 3**  
- **Matplotlib** – core visualization library  
- **Seaborn** – advanced statistical plotting  
- **Plotly** – interactive visualizations  
- **Pandas**, **NumPy** – data manipulation  
- **Jupyter Notebook** – for development and presentation
